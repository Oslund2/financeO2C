# AI Animation Studio

AI-powered animation production platform for creating multi-format content across multiple workspaces.

## Tech Stack

- React 18 + TypeScript + Vite
- Tailwind CSS
- Supabase (database, auth, storage, edge functions)
- Google Cloud Vertex AI (Gemini, Veo 3)
- ElevenLabs (voice synthesis)

## Setup

```bash
npm install
npm run dev
```

## Environment Variables

```env
VITE_SUPABASE_URL=your-supabase-url
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key
```
